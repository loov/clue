## Cross-Phase Integration

### Toolchain Flow
```
internal/build → internal/toolchain/all → gcc/clang/msvc subpackages
```
- `build.NewToolchain()` delegates to `all.NewToolchain()`
- Factory creates `gcc.New()`, `clang.New()`, or `msvc.FindAndNew()`
- All implementations satisfy `toolchain.Toolchain` interface
- **Status: WIRED**

### Cache Flow
```
internal/build/builder.go → internal/cache (Manager, NeedsRebuild, StoreResult)
```
- Builder holds `cache.Manager` field
- `cache.NewManager()` called during builder construction
- `NeedsRebuild()` and `StoreResult()` used for incremental builds
- **Status: WIRED**

### Profile Flow
```
internal/build/builder.go → internal/profile (Profiler, WriteTrace)
```
- Builder holds `profile.Profiler` field
- `profile.NewProfiler()` called during builder construction
- `profiler.WriteTrace()` exports Chrome Trace JSON
- **Status: WIRED**

### Watch Flow
```
main.go → internal/watch (Watcher, Config)
```
- CLI creates `watch.NewWatcher(watch.Config{...})`
- Watcher triggers rebuild callback on file changes
- **Status: WIRED**

### Test Helper Flow

- `testclue.SkipIfNoClangPP()` - 9 uses
