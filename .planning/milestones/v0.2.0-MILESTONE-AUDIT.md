## E2E Flow Verification

### Flow 1: Build with MSVC on Windows

```
clue build -variant release
  → loadConfig() → cfg.Toolchain.Compiler = "msvc"
  → NewToolchain("msvc", target)
    → FindMSVC() → MSVCInstallation
    → &MSVCToolchain{installation}
  → compiler.CompileSource()
    → isMSVC() → compileSourceMSVC()
  → linker.LinkExecutable()
    → isMSVC() → linkExecutableMSVC()
```

**Status:** COMPLETE

### Flow 2: Profile a Build

```
clue build -profile -save-profile -v -top 5
  → opts.Profile = true
  → b.profiler = NewProfiler(true)
  → parallelCompiler.profiler = b.profiler
  → RecordCompilation() after each file
  → PrintSlowestFiles(5, stdout)
  → WriteTrace("profile.json")
```

**Status:** COMPLETE

### Flow 3: Watch and Rebuild

```
clue watch
  → collectSourceDirs(cfg)
  → NewWatcher(WatchConfig{OnRebuild: doBuild})
  → watcher.Start()
  → [file change] → fsnotify event
    → IsRelevantFile(".cpp") → true
    → debounce 300ms
    → OnRebuild() → doBuild()
      → Builder.Build()
  → Ctrl+C → watcher.Stop()
```

**Status:** COMPLETE
