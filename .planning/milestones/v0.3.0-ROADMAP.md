# Milestone v0.3.0: Code Quality

**Status:** SHIPPED 2026-01-29
**Phases:** 13-17
**Total Plans:** 17

## Overview

Code quality milestone focused on refactoring internal/build (originally 55 files, 14,295 lines) into focused packages and adding comprehensive testdata with real-world external library examples. Toolchain extraction came first as the largest, most complex extraction, followed by smaller extractions, build consolidation, and finally testdata projects once the build system was stable.

## Phases

### Phase 13: Toolchain Interface

**Goal**: Establish internal/toolchain package with shared interface, types, and utilities that all toolchain implementations will use
**Depends on**: Phase 12 (v0.2.0 complete)
**Requirements**: REFAC-01
**Plans**: 2 plans

Plans:
- [x] 13-01-PLAN.md - Create toolchain package with interface, types, and utilities
- [x] 13-02-PLAN.md - Update internal/build to import from toolchain package

**Details:**
- Created Toolchain interface with 9 methods
- Moved Config, Platform, CompilerIdentity types to toolchain package
- Exported flag mapping helpers (OptimizationFlag, WarningFlagsForLevel, DebugFlag)
- Used type aliases for API compatibility during refactoring
- Eliminated 280 lines of duplicate code

### Phase 14: Toolchain Implementations

**Goal**: Move GCC, Clang, and MSVC implementations to separate subpackages under internal/toolchain
**Depends on**: Phase 13
**Requirements**: REFAC-02, REFAC-03, REFAC-04
**Plans**: 4 plans

Plans:
- [x] 14-01-PLAN.md - Create gccish package with shared GCC/Clang behavior
- [x] 14-02-PLAN.md - Extract GCC and Clang implementations to subpackages
- [x] 14-03-PLAN.md - Extract MSVC implementation and discovery to subpackage
- [x] 14-04-PLAN.md - Create factory package and update internal/build

**Details:**
- Created gccish package for shared GCC/Clang flag generation
- GCC and Clang packages override only CompilerFlags/LinkerFlags
- MSVC package includes Windows-specific discovery with build tags
- Factory package (toolchain/all) aggregates all implementations
- Net reduction: 719 lines removed from internal/build

## Milestone Summary

**Key Decisions:**

- Move Config, Platform, CompilerIdentity to internal/toolchain (correct dependency direction)
- Use type aliases during refactoring for API compatibility
- Create gccish shared package for GCC/Clang common behavior
- Use build tags for Windows-specific MSVC discovery code
- Rename types to avoid stutter (cache.CacheEntry -> cache.Entry)
- Direct imports from extracted packages, no re-exports in build
- Use testing.TB interface for test helpers (works with Test and Benchmark)
- Create mock Catch2 header instead of downloading (network isolation)

**Issues Resolved:**

- internal/build package size reduced from 55 files to focused orchestration
- Toolchain code duplication eliminated through shared interface and gccish package
- Test code duplication eliminated through internal/testclue package
- Transitive dependency linking bug fixed in multi-deps-example

**Issues Deferred:**

- None

**Technical Debt Incurred:**

- None
