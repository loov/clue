<task type="auto">
  <name>Task 1: Create MSVCToolchain struct and interface implementation</name>
  <files>internal/build/toolchain_msvc.go</files>
  <action>
Create toolchain_msvc.go following GCCToolchain/ClangToolchain pattern:

1. MSVCToolchain struct with fields:
   - installation *MSVCInstallation (from discovery)
   - target Platform

2. Implement all 9 Toolchain interface methods:

   CC() string:
   - Return path to cl.exe from installation environment PATH
   - Format: first directory in PATH containing cl.exe

   CXX() string:
   - Return same cl.exe path (MSVC uses cl.exe for both C and C++)

   AR() string:
   - Return path to lib.exe from installation environment PATH

   Name() string:
   - Return "msvc"

   IsCrossCompiler() bool:
   - Return false (cross-compilation deferred to v0.3.0 per requirements)

   String() string:
   - Return "msvc (native)" format matching GCC/Clang pattern

   Identity() (CompilerIdentity, error):
   - Run cl.exe (no args) and parse version from banner output
   - MSVC banner format: "Microsoft (R) C/C++ Optimizing Compiler Version 19.40..."
   - Extract version number for cache key

3. MSVC-specific flag mapping tables:

   msvcOptimizationFlags map[string]string:
   - "none" -> "/Od"
   - "size" -> "/O1"
   - "fast" -> "/O2"
   - "aggressive" -> "/O2" (MSVC has no /O3)

   msvcWarningFlags map[string][]string:
   - "off" -> {"/W0"}
   - "default" -> {"/W3"}
   - "strict" -> {"/W4"}
   - "pedantic" -> {"/W4", "/permissive-"}

   msvcDebugFlags map[string]string:
   - "none" -> ""
   - "minimal" -> "/Z7"
   - "full" -> "/Zi"

4. CompilerFlags(config Config) []string implementation:
   - Always start with /nologo (suppress banner per CONTEXT.md)
   - Add optimization flag from msvcOptimizationFlags
   - Add warning flags from msvcWarningFlags
   - Add /WX if config.WarningsAsErrors
   - Add debug flag from msvcDebugFlags
   - Add CRT flag: /MTd for debug, /MT for release (per CONTEXT.md default)
   - Add /EHsc for C++ exception handling
   - Skip sanitizers for v0.2.0 (MSVC sanitizer support is limited)
   - Skip LTO for v0.2.0 (/GL and /LTCG are complex)
   - Add /showIncludes for dependency tracking
   - Append config.RawCompiler flags

5. LinkerFlags(config Config, sysLibs []string) []string implementation:
   - Always start with /nologo
   - Add /DEBUG if debug != "none"
   - Add system libraries (without -l prefix, MSVC uses foo.lib format)
   - Append config.RawLinker flags
   - Note: MSVC linking is done via link.exe, not cl.exe

Add compile-time interface check:
var _ Toolchain = (*MSVCToolchain)(nil)
