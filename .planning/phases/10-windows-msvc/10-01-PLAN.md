<task type="auto">
  <name>Task 2: Implement Windows-specific VS discovery</name>
  <files>internal/build/msvc_discovery_windows.go</files>
  <action>
Create msvc_discovery_windows.go with //go:build windows:

1. FindMSVC() implementation:
   - Check for CLUE_MSVC_PATH environment variable first (allows user override)
   - If not set, locate vswhere.exe at standard path
   - If vswhere.exe not found, return newMSVCNotFoundError()
   - Execute vswhere.exe with args:
     `-latest -products * -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64 -property installationPath -format json`
   - Parse JSON output to get installation path
   - If no installation found, return newMSVCNotFoundError()

2. findVCToolsPath(vsPath string) helper:
   - Locate VC/Tools/MSVC subdirectory
   - Find newest version directory (sort by version)
   - Return path to tools (e.g., vsPath/VC/Tools/MSVC/14.40.33807)

3. captureVCVarsEnvironment(vsPath, arch string) helper:
   - Build vcvarsall.bat path: vsPath/VC/Auxiliary/Build/vcvarsall.bat
   - Create temp batch script that calls vcvarsall and dumps environment via SET
   - Execute with cmd.exe /c
   - Parse KEY=VALUE lines into map[string]string
   - Handle errors gracefully (vcvarsall.bat may fail)

4. Architecture detection:
   - Default to "x64" for 64-bit Windows
   - Support "x86" via environment variable or future config

Error handling per CONTEXT.md:
- When VS not found: return error with message "MSVC not found. Install Visual Studio: https://visualstudio.microsoft.com/downloads/"
- When vcvarsall.bat fails: return detailed error with exit code
  </action>
  <verify>
Run: GOOS=windows go build ./internal/build/
Windows build compiles (cross-compile check).
  </verify>
  <done>findVisualStudio finds VS installation via vswhere.exe and captureVCVarsEnvironment captures vcvarsall.bat output.</done>
</task>
