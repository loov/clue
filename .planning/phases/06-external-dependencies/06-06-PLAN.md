<task type="auto">
  <name>Task 1: Implement deps command handlers</name>
  <files>internal/deps/commands.go</files>
  <action>
Create command implementations for deps subcommands:

1. `RunList(cfg *config.Config, verbose bool) error`:
   - Create Manager from config.Dependencies
   - Get status via manager.Status()
   - Print formatted table:
     ```
     Dependencies:
       NAME       TYPE       STATUS     LOCATION
       libfoo     git        cached     .deps/git/libfoo-main
       libbar     tarball    missing    -
       vendor     vendored   cached     vendor/libvendor
     ```
   - If verbose, show additional info (ref, checksum prefix)
   - Return nil

2. `RunFetch(ctx context.Context, cfg *config.Config, opts FetchOptions) error`:
   - `FetchOptions`: verbose, ciMode, name (optional for single dep)
   - Create Manager
   - If opts.Name != "", call manager.FetchOne(ctx, opts.Name)
   - Else call manager.FetchAll(ctx)
   - Print summary: "Fetched {N} dependencies ({M} cached, {K} downloaded)"
   - Return nil on success

3. `RunUpdate(ctx context.Context, cfg *config.Config, opts UpdateOptions) error`:
   - For git deps with branch refs: check if remote has newer commits
   - For tarball deps: re-download and compare checksums
   - Print what would be updated
   - If --apply flag: actually update
   - "git:libfoo (main) has updates available"
   - Note: Full update implementation is optional for Phase 6; can just print "Update checking not yet implemented"

4. `RunClean(cfg *config.Config, name string) error`:
   - If name != "", call manager.CleanOne(name)
   - Else call manager.Clean()
   - Print "Cleaned dependency cache" or "Removed {name} from cache"

5. Helper `formatDepStatus(status DepStatus) string`:
   - Return formatted row for table output
  </action>

Add deps subcommand to main CLI:

1. Add new flag set for deps command:
   ```go
   depsCmd := flag.NewFlagSet("deps", flag.ExitOnError)
   depsVerbose := depsCmd.Bool("verbose", false, "Show detailed information")
   depsCI := depsCmd.Bool("ci", false, "Enable CI mode (strict validation)")
   ```

2. Add deps case to main switch:
   ```go
   case "deps":
       if len(os.Args) < 3 {
           fmt.Println("Usage: clue deps <list|fetch|update|clean> [options]")
           os.Exit(1)
       }

       subCmd := os.Args[2]
       depsCmd.Parse(os.Args[3:])

       cfg, err := loadConfig(*dir, "")
       if err != nil {
           fmt.Fprintln(os.Stderr, err)
           os.Exit(1)
       }

       switch subCmd {
       case "list":
           if err := deps.RunList(cfg, *depsVerbose); err != nil {
               fmt.Fprintln(os.Stderr, err)
               os.Exit(1)
           }
       case "fetch":
           name := ""
           if depsCmd.NArg() > 0 {
               name = depsCmd.Arg(0)
           }
           if err := deps.RunFetch(ctx, cfg, deps.FetchOptions{
               Verbose: *depsVerbose,
               CIMode:  *depsCI,
               Name:    name,
           }); err != nil {
               fmt.Fprintln(os.Stderr, err)
               os.Exit(1)
           }
       case "update":
           // Optional: implement or print "not yet implemented"
           fmt.Println("Dependency update checking not yet implemented")
       case "clean":
           name := ""
           if depsCmd.NArg() > 0 {
               name = depsCmd.Arg(0)
           }
           if err := deps.RunClean(cfg, name); err != nil {
               fmt.Fprintln(os.Stderr, err)
               os.Exit(1)
           }
       default:
           fmt.Printf("Unknown deps subcommand: %s\n", subCmd)
           os.Exit(1)
       }
   ```

3. Update help text to include deps command:
   ```
   Commands:
     build     Build targets
     clean     Remove build artifacts
     validate  Check configuration
     deps      Manage dependencies
       list    Show dependency status
       fetch   Download dependencies
       clean   Remove dependency cache
   ```

4. Handle --ci flag in fetch to enable strict mode
