<task type="auto">
  <name>Task 2: Extend CUE schema with dependency definitions</name>
  <files>internal/config/schema.cue</files>
  <action>
Add dependency schema definitions to schema.cue:

1. Add `#GitDependency` definition:
```cue
#GitDependency: {
    type: "git"
    repo: string & =~"^(https?://|git@)"  // Must be valid git URL
    ref?: string | *"main"
    build?: #InlineBuildConfig
}
```

2. Add `#TarballDependency` definition:
```cue
#TarballDependency: {
    type: "tarball"
    url: string & =~"^https?://"
    checksum?: string & =~"^[a-f0-9]{64}$"  // SHA256 hex
    stripPrefix?: string
    build?: #InlineBuildConfig
}
```

3. Add `#VendoredDependency` definition:
```cue
#VendoredDependency: {
    type: "vendored"
    path: string
    build?: #InlineBuildConfig
}
```

4. Add `#InlineBuildConfig` for deps without clue.cue:
```cue
#InlineBuildConfig: {
    sources: [...string] & [_, ...]
    includes?: [...string]
    defines?: [...string]
    targetType?: "static_library" | "shared_library" | *"static_library"
}
```

5. Add union type and dependencies block to #Config:
```cue
#Dependency: #GitDependency | #TarballDependency | #VendoredDependency

#Config: {
    // ... existing fields ...
    dependencies?: [string]: #Dependency
}
```

Note: The `name` field comes from the map key in dependencies block, not from the dependency itself.
  </action>
  <verify>Create a test clue.cue with dependencies and run `go test ./internal/config/...`</verify>
  <done>CUE schema validates dependency definitions with type-specific constraints</done>
</task>
