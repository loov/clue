<task type="auto">
  <name>Task 1: Implement safe archive extraction</name>
  <files>internal/deps/extract.go</files>
  <action>
Create secure archive extraction functions:

1. `ExtractTarGz(archivePath, targetDir string) error`:
   - Open file, wrap in gzip.NewReader, then tar.NewReader
   - For each entry:
     a. Validate path with `filepath.IsLocal(hdr.Name)` - return error if false
     b. Resolve full path: `filepath.Join(targetDir, hdr.Name)`
     c. Additional check: verify resolved absolute path is within targetDir
        ```go
        absTarget, _ := filepath.Abs(fullPath)
        absDir, _ := filepath.Abs(targetDir)
        if !strings.HasPrefix(absTarget, absDir+string(filepath.Separator)) {
            return fmt.Errorf("path traversal detected: %s", hdr.Name)
        }
        ```
     d. Handle entry types:
        - TypeDir: `os.MkdirAll(fullPath, 0755)`
        - TypeReg: create file, copy contents, set permissions from header
        - TypeSymlink, TypeLink: skip (security risk)
        - Other: skip with warning if verbose
   - Close all readers/writers properly
   - Return nil on success

2. `ExtractZip(archivePath, targetDir string) error`:
   - Similar pattern using archive/zip
   - Same path validation logic
   - Handle directory entries and regular files

3. `StripPrefix(dir, prefix string) error`:
   - Used when tarball has a root directory that should be stripped
   - Move contents of `dir/prefix/*` to `dir/*`
   - Remove the now-empty prefix directory
   - Common for GitHub release tarballs (e.g., `libfoo-1.0.0/`)

4. `DetectArchiveType(path string) string`:
   - Return "tar.gz" for .tar.gz, .tgz
   - Return "zip" for .zip
   - Return "" for unknown (error case)

All functions should:
- Return descriptive errors with file context
- Handle partial extraction cleanup on error (remove targetDir)
- NOT follow symlinks anywhere
  </action>

  <done>Safe archive extraction with path traversal prevention</done>

<task type="auto">
  <name>Task 2: Implement tarball fetcher</name>
  <files>internal/deps/tarball_fetcher.go</files>
  <action>
Create tarball fetcher with download and verification:

1. `TarballFetcher` struct:
   - `verbose bool`
   - `ciMode bool` (strict checksum enforcement)

2. `NewTarballFetcher(verbose, ciMode bool) *TarballFetcher`

3. `Fetch(ctx context.Context, dep *TarballDependency, targetPath string) error`:
   - Create temp file for download
   - Download with checksum computation:
     ```go
     resp, err := http.Get(dep.URL)
     // ... error handling, status code check ...

     h := sha256.New()
     tmpFile, _ := os.CreateTemp("", "clue-dep-*")
     w := io.MultiWriter(tmpFile, h)

     _, err = io.Copy(w, resp.Body)
     actualChecksum := hex.EncodeToString(h.Sum(nil))
     ```
   - Checksum verification:
     ```go
     if dep.Checksum != "" {
         if actualChecksum != dep.Checksum {
             os.Remove(tmpFile.Name())
             return fmt.Errorf("checksum mismatch for %s: expected %s, got %s",
                 dep.Name, dep.Checksum, actualChecksum)
         }
     } else {
         if f.ciMode {
             os.Remove(tmpFile.Name())
             return fmt.Errorf("dependency %s missing checksum (required in CI mode)", dep.Name)
         }
         // Warning in non-CI mode
         fmt.Printf("Warning: %s has no checksum verification\n", dep.Name)
     }
     ```
   - Detect archive type and extract:
     ```go
     archiveType := DetectArchiveType(dep.URL)
     switch archiveType {
     case "tar.gz":
         err = ExtractTarGz(tmpFile.Name(), targetPath)
     case "zip":
         err = ExtractZip(tmpFile.Name(), targetPath)
     default:
         return fmt.Errorf("unsupported archive format: %s", dep.URL)
     }
     ```
   - Handle stripPrefix if specified
   - Clean up temp file
   - Return nil on success

4. Progress reporting (verbose):
   - "Downloading {url}..."
   - "Download complete ({size} bytes)"
   - "Checksum verified: {checksum}"
   - "Extracting to {path}..."
   - "Extracted {N} files"

5. Context cancellation:
   - Use `http.NewRequestWithContext(ctx, "GET", dep.URL, nil)`
   - Check ctx.Err() periodically during extraction
