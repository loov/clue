<task type="auto">
  <name>Task 1: Implement dependency builder</name>
  <files>internal/deps/dep_builder.go</files>
  <action>
Create builder for individual dependencies:

1. `DepBuilder` struct:
   - `compiler *build.Compiler` (from main build package)
   - `linker *build.Linker`
   - `toolchain *build.Toolchain`
   - `verbose bool`

2. `NewDepBuilder(compiler *build.Compiler, linker *build.Linker, toolchain *build.Toolchain, verbose bool) *DepBuilder`

3. `BuildDep(ctx context.Context, dep Dependency, sourcePath string, opts DepBuildOptions) (*DepBuildResult, error)`:
   - `DepBuildOptions`:
     - `Variant string`
     - `Platform build.Platform`
     - `BuildDir string`
     - `Verbose bool`
   - `DepBuildResult`:
     - `Name string`
     - `LibPath string` (path to built .a file)
     - `IncludePath string` (path to include headers)
     - `SourceCount int`
     - `Duration time.Duration`

4. Build process:
   a. Determine sources:
      - If dep has inline config: use config.Sources
      - Else if clue.cue exists in sourcePath: load and use first target's sources
      - Else: error "no build configuration for dependency {name}"
   b. Collect source files (resolve globs relative to sourcePath)
   c. Create object directory: `.build/variant/deps/{name}/obj/`
   d. Compile each source to object file:
      ```go
      for _, src := range sources {
          absPath := filepath.Join(sourcePath, src)
          objPath := filepath.Join(objDir, filepath.Base(src)+".o")
          // Use existing compiler.CompileSource
      }
      ```
   e. Create static library: `.build/variant/deps/{name}/lib/lib{name}.a`
   f. Return result with paths

5. Collapsed output (when not verbose):
   - Print single line: "Building {name} [{N} files]"
   - Expand on error: show full compiler output
   - When verbose: show each file being compiled

6. Include path determination:
   - If dep has inline config with `includes`: use those
   - Else: default to sourcePath (all headers in root)
   - Common pattern: `{sourcePath}/include` if it exists
  </action>
  <verify>go build ./internal/deps/... compiles without errors</verify>
  <done>Dependency builder compiles sources to static library</done>
</task>

<task type="auto">
  <name>Task 2: Integrate dependency building into main builder</name>
  <files>internal/build/builder.go</files>
  <action>
Extend main Builder to build dependencies first:

1. Add field to `BuildOptions`:
   ```go
   SkipDeps bool // Skip dependency building (for `clue deps build`)
   ```

2. Add method `buildDependencies(ctx context.Context, opts BuildOptions) (map[string]*deps.DepBuildResult, error)`:
   - Get dependencies from opts.Config.Dependencies
   - If no dependencies, return empty map
   - Create deps.Manager and ensure deps are fetched
   - Get build order from manager.Resolver.BuildOrder()
   - For each dependency:
     a. Get source path from cache
     b. Build with DepBuilder
     c. Store result in map
   - Return map of name -> result

3. Modify `Build()` method:
   - Before building targets, call buildDependencies if not SkipDeps
   - Print "Building dependencies..." before dep builds
   - Store dep results for linking

4. Modify `BuildTarget()` to use dependency libraries:
   - For each target.Depends that references a dependency (not another target):
     a. Get dep result from built deps map
     b. Add dep.LibPath to linker -L paths
     c. Add dep name to -l libraries
     d. Add dep.IncludePath to include paths
   - Existing target-to-target deps continue to work

5. Dependency detection:
   - If name in target.Depends exists in config.Dependencies: it's a dep
   - If name in target.Depends exists in config.Targets: it's a target
   - Else: error "unknown dependency or target: {name}"

Progress output:

```
  Building libbar [2 files]

Building for linux-amd64
[1/3] myapp: main.cpp
...
```
  </action>
  <verify>go build ./... compiles without errors</verify>
  <done>Main builder builds dependencies before targets</done>
</task>
