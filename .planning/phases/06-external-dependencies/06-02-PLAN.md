<task type="auto">
  <name>Task 1: Implement dependency cache manager</name>
  <files>internal/deps/cache.go</files>
  <action>
Create cache manager that tracks fetched dependencies:

1. `Cache` struct:
   - `baseDir string` (project root directory)
   - `depsDir string` (path to .deps directory)
   - `verbose bool`

2. `NewCache(projectDir string, verbose bool) *Cache`:
   - Sets `depsDir` to `filepath.Join(projectDir, ".deps")`
   - Creates .deps directory if it doesn't exist

3. `Has(dep Dependency) bool`:
   - Returns true if dependency is already fetched
   - For git: checks if `.deps/git/{name}-{ref}/` exists and has .git directory
   - For tarball: checks if `.deps/tarball/{name}-{checksum}/` exists
   - For vendored: checks if the original path exists (always "cached")

4. `Path(dep Dependency) string`:
   - Returns the local path where dependency sources are located
   - Delegates to dep.CachePath(c.depsDir)

5. `MarkFetched(dep Dependency) error`:
   - Creates a `.clue-dep` marker file in the cache directory
   - Contains JSON: `{name, type, fetched_at, ref/url/path}`
   - Used to verify cache integrity

6. `Clean() error`:
   - Removes entire .deps directory
   - Returns nil if directory doesn't exist

7. `CleanDep(name string) error`:
   - Removes specific dependency from cache
   - Searches all subdirs (git/, tarball/) for matching name

Include verbose logging when operations occur.
  </action>
  <verify>go build ./internal/deps/... compiles without errors</verify>
  <done>Cache manager tracks dependency locations and provides Has/Path/Clean operations</done>
</task>

<task type="auto">
  <name>Task 2: Implement git fetcher with go-git</name>
  <files>internal/deps/git_fetcher.go, go.mod</files>
  <action>
Create git fetcher using go-git library:

1. First, add go-git dependency:
   - Add `github.com/go-git/go-git/v5` to imports

2. `GitFetcher` struct:
   - `verbose bool`

3. `NewGitFetcher(verbose bool) *GitFetcher`

4. `Fetch(ctx context.Context, dep *GitDependency, targetPath string) error`:
   - Use shallow clone (Depth: 1) by default for speed
   - Clone options:
     ```go
     opts := &git.CloneOptions{
         URL:           dep.Repo,
         Depth:         1,
         SingleBranch:  true,
         ReferenceName: plumbing.NewBranchReferenceName(dep.Ref),
         Progress:      progressWriter, // os.Stdout if verbose
     }
     ```
   - Handle tags: if ref looks like a tag (starts with "v" or contains "."), try as tag reference first
   - Fallback to full clone if shallow fails (for pinned commits):
     ```go
     if err != nil && isShallowError(err) {
         opts.Depth = 0
         _, err = git.PlainCloneContext(ctx, targetPath, false, opts)
     }
     ```
   - Return wrapped error with context: "failed to clone %s: %w"

5. Progress reporting:
   - If verbose, print "Cloning {repo} ({ref})..."
   - On success, print "Cloned {repo} at {short-commit-hash}"

6. Helper `isShallowError(err error) bool`:
   - Returns true for errors that indicate shallow clone failed
   - Check for `git.ErrReferenceNotFound` or similar

Handle context cancellation for clean abort on Ctrl+C.
  </action>
  <verify>go build ./internal/deps/... compiles (may need go get for go-git)</verify>
  <done>Git fetcher clones repositories with shallow clone default and fallback</done>
</task>

<task type="auto">
  <name>Task 3: Implement vendored fetcher</name>
  <files>internal/deps/vendored_fetcher.go</files>
  <action>
Create vendored fetcher that validates local paths:

1. `VendoredFetcher` struct:
   - `projectDir string` (to resolve relative paths)
   - `verbose bool`

2. `NewVendoredFetcher(projectDir string, verbose bool) *VendoredFetcher`

3. `Fetch(ctx context.Context, dep *VendoredDependency, targetPath string) error`:
   - For vendored deps, "fetching" means validating the path exists
   - Resolve relative path: `filepath.Join(f.projectDir, dep.Path)`
   - Check directory exists: `os.Stat(absPath)`
   - Return error if not found: "vendored dependency %s not found at %s"
   - Check for clue.cue or build config: warn if neither present
   - Return nil on success (no actual fetching needed)

4. `Path(dep *VendoredDependency) string`:
   - Returns the resolved absolute path
   - Does NOT use .deps directory - vendored deps stay in place

5. Verbose output:
   - Print "Validating vendored dependency {name} at {path}..."
   - On success: "Found vendored dependency {name} ({N} source files)"
   - If no clue.cue and no inline config: "Warning: {name} has no build configuration"

Note: Vendored dependencies don't need caching - they're already local. The "fetch" operation is really just validation.
  </action>
  <verify>go build ./internal/deps/... compiles without errors</verify>
  <done>Vendored fetcher validates local paths and reports configuration status</done>
