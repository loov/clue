Create internal/build/watcher.go with Watcher type.

**WatchConfig struct:**
```go
type WatchConfig struct {
    SourceDirs    []string      // Directories to watch
    BuildCuePath  string        // Path to build.cue for config change detection
    DebounceDur   time.Duration // Debounce window (default 300ms)
    OnRebuild     func(trigger string, isConfigChange bool) // Callback when rebuild needed
}
```

**Watcher struct fields:**
- watcher *fsnotify.Watcher
- config WatchConfig
- debounceTimer *time.Timer
- mu sync.Mutex (protect timer)
- done chan struct{}
- pendingTrigger string (file that triggered rebuild)
- isConfigChange bool (track if config changed)

**NewWatcher(cfg WatchConfig) (*Watcher, error):**
1. Create fsnotify.NewWatcher()
2. Add each SourceDir to watcher
3. If BuildCuePath != "", add its parent directory
4. Store config
5. Return watcher

**(*Watcher) Start() error:**
1. Launch goroutine with event loop
2. On watcher.Events: filter by extension, reset debounce timer
3. On watcher.Errors: log and continue
4. When debounce fires: call OnRebuild(trigger, isConfigChange), reset pending state

**(*Watcher) Stop():**
1. Close done channel
2. Stop watcher

**isRelevantFile(path string) bool:**
Return true for .c, .cpp, .h, .hpp, .cue extensions only.
Use filepath.Ext() and switch statement.

**Event filtering:**
- Ignore Chmod events (only Create, Write, Remove, Rename)
- Track pendingTrigger as the first file in debounce window
- Set isConfigChange = true if file ends with "build.cue" or ".cue"

**Debounce pattern (from research):**
```go
if w.debounceTimer != nil {
    w.debounceTimer.Stop()
}
w.debounceTimer = time.AfterFunc(w.config.DebounceDur, func() {
    w.config.OnRebuild(w.pendingTrigger, w.isConfigChange)
    // Reset state for next batch
    w.pendingTrigger = ""
    w.isConfigChange = false
})
```

Default DebounceDur: 300 * time.Millisecond (within 300-500ms range per CONTEXT.md)
