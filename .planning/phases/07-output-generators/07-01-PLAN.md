  <action>
Add LinkSharedLibrary method to Linker struct:

1. Create SharedLibraryOptions struct:
   - Objects []string (object files to link)
   - Output string (output .so/.dylib path)
   - SysLibs []string (system libraries)
   - LibPaths []string (library search paths)
   - Libs []string (additional libraries)
   - Flags BuildConfig
   - UseCPlusPlus bool
   - SymbolVisibility string ("default" or "hidden")

2. Implement LinkSharedLibrary method:
   - Add -shared flag
   - macOS: Add -install_name @rpath/libname.dylib using filepath.Base(output)
   - Linux: Add -Wl,-soname,libname.so using filepath.Base(output)
   - If SymbolVisibility == "hidden", add -fvisibility=hidden at link time
   - Create output directory with MkdirAll
   - Execute linker command

3. Add tests in linker_test.go:
   - TestLinkSharedLibrary_CommandConstruction
   - TestLinkSharedLibrary_MacOSInstallName
   - TestLinkSharedLibrary_LinuxSONAME
