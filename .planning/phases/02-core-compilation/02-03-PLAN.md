<task type="auto">
  <name>Task 1: Create compiler implementation</name>
  <files>internal/build/compiler.go</files>
  <action>
Create internal/build/compiler.go with compiler invocation logic:

1. Define CompileOptions struct:
   ```go
   type CompileOptions struct {
       Source      string            // Source file path
       Output      string            // Output object file path
       Includes    []string          // Include directories
       Defines     []string          // Preprocessor defines
       Flags       BuildConfig       // Semantic flags
       Std         string            // Language standard (e.g., "c++20", "c17")
   }
   ```

2. Define CompileResult struct:
   ```go
   type CompileResult struct {
       Source   string
       Object   string
       Duration time.Duration
       Success  bool
   }
   ```

3. Define Compiler type:
   ```go
   type Compiler struct {
       executor *Executor
       toolchain string  // "clang" or "gcc"
   }

   func NewCompiler(executor *Executor, toolchain string) *Compiler
   ```

4. Implement language detection helper:
   ```go
   func (c *Compiler) isCPlusPlus(source string) bool
   ```
   Returns true if source ends with .cpp, .cc, .cxx, .C, .CPP

5. Implement compiler selection:
   ```go
   func (c *Compiler) compilerCmd(source string) string
   ```
   - If toolchain is "clang": return "clang++" for C++, "clang" for C
   - If toolchain is "gcc": return "g++" for C++, "gcc" for C
   - Default to clang-based

6. Implement CompileSource method:
   ```go
   func (c *Compiler) CompileSource(ctx context.Context, opts CompileOptions) (*CompileResult, error)
   ```

   Build command arguments in order:
   a. -c (compile only, don't link)
   b. Source file
   c. -o output.o
   d. Include paths: for each include, add -I{path}
   e. Defines: for each define, add -D{define}
   f. Standard: if opts.Std non-empty, add -std={std}
   g. Semantic flags: call BuildCompilerFlags(opts.Flags)
   h. Raw compiler flags from opts.Flags.RawCompiler

   Create output directory if it doesn't exist (filepath.Dir(opts.Output)).

   Use executor.RunCompiler to execute.

   Return CompileResult with timing and success status.

7. Implement batch compilation (fail-fast):
   ```go
   func (c *Compiler) CompileSources(ctx context.Context, sources []CompileOptions) ([]CompileResult, error)
   ```
   Compile each source in order. On first error, stop and return error.
   Return all successful results up to the failure.
  </action>
