<task type="auto">
  <name>Task 2: Create build orchestration</name>
  <files>internal/build/builder.go</files>
  <action>
Create internal/build/builder.go with high-level build logic:

1. Define BuildOptions struct:
   ```go
   type BuildOptions struct {
       Config    *config.Config
       Variant   string          // "debug" or "release"
       BuildDir  string          // Build output root (default: "build")
       Verbose   bool            // Show full compiler commands
       Targets   []string        // Specific targets to build (empty = all)
   }
   ```

2. Define TargetResult struct:
   ```go
   type TargetResult struct {
       Name     string
       Type     string        // "executable" or "static_library"
       Output   string        // Path to output artifact
       Sources  int           // Number of source files
       Duration time.Duration
       Success  bool
   }
   ```

3. Define BuildResult struct:
   ```go
   type BuildResult struct {
       Targets  []TargetResult
       Duration time.Duration
       Success  bool
   }
   ```

4. Define Builder type:
   ```go
   type Builder struct {
       executor *Executor
       compiler *Compiler
       linker   *Linker
       progress *Progress
   }

   func NewBuilder(toolchain string, verbose bool) *Builder
   ```

5. Implement path helpers:
   ```go
   // ObjectDir returns build/variant/target/ for object files
   func (b *Builder) ObjectDir(buildDir, variant, target string) string

   // OutputPath returns the final artifact path
   // Executable: build/variant/bin/target
   // Static lib: build/variant/lib/libtarget.a
   func (b *Builder) OutputPath(buildDir, variant, target, targetType string) string
   ```

6. Implement BuildTarget method:
   ```go
   func (b *Builder) BuildTarget(ctx context.Context, opts BuildOptions, target config.Target) (*TargetResult, error)
   ```

   Steps:
   a. Calculate object directory and output path
   b. Create directories
   c. For each source file:
      - Call progress.Compiling()
      - Build CompileOptions from target config
      - Convert semantic flags from target to BuildConfig
      - Call compiler.CompileSource()
      - If verbose, log command
      - On error, return immediately (fail-fast)
   d. Based on target.Type:
      - "executable": call linker.LinkExecutable
      - "static_library": call linker.CreateStaticLibrary
   e. Call progress.Complete()
   f. Return TargetResult

7. Implement Build method:
   ```go
   func (b *Builder) Build(ctx context.Context, opts BuildOptions) (*BuildResult, error)
   ```

   Steps:
   a. Get build order from config (respects target dependencies)
   b. Count total source files for progress
   c. For each target in order:
      - Skip if specific targets requested and this isn't one
      - Build target
      - On error, stop and return (fail-fast)
   d. Return BuildResult

8. Implement helper to convert config.Target to BuildConfig:
   ```go
   func (b *Builder) targetToBuildConfig(target config.Target, variant config.Variant) BuildConfig
   ```
   Maps: target.Optimize, target.Warnings, etc. to BuildConfig fields.
   Apply variant flags on top of target flags.
  </action>
