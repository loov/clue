<task type="auto">
  <name>Task 2: Create semantic flag mapping implementation</name>
  <files>internal/build/flags.go</files>
  <action>
Create internal/build/flags.go with semantic flag to compiler flag mapping:

1. Create the build package directory: `internal/build/`

2. Define BuildConfig struct to hold semantic flag values:
   ```go
   type BuildConfig struct {
       Optimize         string   // "none", "size", "fast", "aggressive"
       Warnings         string   // "off", "default", "strict", "pedantic"
       WarningsAsErrors bool     // Default true
       Debug            string   // "none", "minimal", "full"
       RawCompiler      []string // Pass-through compiler flags
       RawLinker        []string // Pass-through linker flags
   }
   ```

3. Implement flag mapping tables (from RESEARCH.md):
   - optimizationFlags: none->-O0, size->-Os, fast->-O2, aggressive->-O3
   - warningFlags: off->[], default->[-Wall], strict->[-Wall,-Wextra], pedantic->[-Wall,-Wextra,-Wpedantic]
   - debugFlags: none->"", minimal->-g1, full->-g

4. Implement BuildCompilerFlags(config BuildConfig) []string:
   - Append optimization flag
   - Append warning flags
   - If WarningsAsErrors: append -Werror
   - Append debug flag (if not empty)
   - Append raw compiler flags

5. Implement BuildLinkerFlags(config BuildConfig, sysLibs []string) []string:
   - For each sysLib: append -l{lib}
   - Append debug flag (linker may need it for debug symbols)
   - Append raw linker flags

6. Handle empty/default values gracefully (no panic on missing keys).
  </action>
  <verify>
Run: `go build ./internal/build/...` compiles without errors
  </verify>
  <done>internal/build/flags.go exists with BuildCompilerFlags and BuildLinkerFlags functions</done>
</task>
