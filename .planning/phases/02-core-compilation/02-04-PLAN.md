<task type="auto">
  <name>Task 1: Create linker implementation</name>
  <files>internal/build/linker.go</files>
  <action>
Create internal/build/linker.go with linker and archiver logic:

1. Define LinkOptions struct:
   ```go
   type LinkOptions struct {
       Objects     []string    // Object files to link
       Output      string      // Output executable path
       SysLibs     []string    // System libraries (pthread, m, dl)
       LibPaths    []string    // Library search paths (-L)
       Libs        []string    // Additional libraries to link
       Flags       BuildConfig // For raw linker flags and debug info
       UseCPlusPlus bool       // Use clang++/g++ for linking (C++ std lib)
   }
   ```

2. Define ArchiveOptions struct:
   ```go
   type ArchiveOptions struct {
       Objects []string  // Object files to archive
       Output  string    // Output static library path (e.g., libfoo.a)
   }
   ```

3. Define LinkResult struct:
   ```go
   type LinkResult struct {
       Output   string
       Duration time.Duration
       Success  bool
   }
   ```

4. Define Linker type:
   ```go
   type Linker struct {
       executor  *Executor
       toolchain string  // "clang" or "gcc"
   }

   func NewLinker(executor *Executor, toolchain string) *Linker
   ```

5. Implement LinkExecutable method:
   ```go
   func (l *Linker) LinkExecutable(ctx context.Context, opts LinkOptions) (*LinkResult, error)
   ```

   Build command arguments:
   a. All object files first
   b. -o output
   c. Library search paths: for each path, add -L{path}
   d. Additional libs: for each lib, add -l{lib}
   e. System libs: for each sysLib, add -l{sysLib}
   f. Linker flags from BuildLinkerFlags(opts.Flags, opts.SysLibs)
   g. Raw linker flags from opts.Flags.RawLinker

   Select linker:
   - If opts.UseCPlusPlus: use clang++/g++ (for C++ std lib linkage)
   - Else: use clang/gcc

   Create output directory if needed.

   Execute via executor.RunCommand and return LinkResult.

6. Implement CreateStaticLibrary method:
   ```go
   func (l *Linker) CreateStaticLibrary(ctx context.Context, opts ArchiveOptions) (*LinkResult, error)
   ```

   Use `ar crs` command:
   - c: create archive
   - r: replace/insert files
   - s: create symbol table (ranlib functionality)

   Command: `ar crs output.a obj1.o obj2.o ...`

   Create output directory if needed.

   Execute via executor.RunCommand and return LinkResult.

7. Implement helper to determine if C++ linking needed:
   ```go
   func (l *Linker) needsCPlusPlusLinker(objects []string) bool
   ```
   Returns true if any object was compiled from a C++ source.
   Note: For now, just check if any object path suggests C++ origin (heuristic).
   Better approach: track language during compilation (can be enhanced later).
  </action>

Run: `go build ./internal/build/...` compiles without errors
