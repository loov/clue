<task type="auto">
  <name>Task 1: Create executor infrastructure</name>
  <files>internal/build/executor.go</files>
  <action>
Create internal/build/executor.go with subprocess management:

1. Define CommandResult struct:
   ```go
   type CommandResult struct {
       ExitCode int
       Stdout   string  // Captured if not streaming
       Stderr   string  // Captured if not streaming
       Duration time.Duration
   }
   ```

2. Define ExecutorConfig struct:
   ```go
   type ExecutorConfig struct {
       Verbose     bool      // If true, print commands before execution
       StreamOutput bool     // If true, stream to os.Stdout/Stderr; if false, capture
       WorkDir     string    // Working directory for commands
   }
   ```

3. Define Executor type:
   ```go
   type Executor struct {
       config ExecutorConfig
   }

   func NewExecutor(config ExecutorConfig) *Executor
   ```

4. Implement RunCommand method:
   ```go
   func (e *Executor) RunCommand(ctx context.Context, name string, args ...string) (*CommandResult, error)
   ```

   Implementation details:
   - Use exec.CommandContext for cancellation support
   - Set cmd.Dir to e.config.WorkDir if specified
   - If StreamOutput: set cmd.Stdout = os.Stdout, cmd.Stderr = os.Stderr
   - If not StreamOutput: capture via bytes.Buffer
   - If Verbose: print command before execution (fmt.Printf("[exec] %s %s\n", name, strings.Join(args, " ")))
   - Extract exit code from exec.ExitError via syscall.WaitStatus
   - Return CommandResult with exit code, captured output, and duration

5. Implement helper method for compiler-style error:
   ```go
   func (e *Executor) RunCompiler(ctx context.Context, compiler string, args []string) error
   ```

   This wraps RunCommand and returns a formatted error on failure:
   - If exit code != 0: return fmt.Errorf("compiler failed with exit code %d", exitCode)
   - Compiler output should stream to terminal (set StreamOutput=true internally)

6. Add a method to check if a tool exists:
   ```go
   func (e *Executor) ToolExists(name string) bool
   ```
   Uses exec.LookPath to check if tool is available in PATH.
  </action>
