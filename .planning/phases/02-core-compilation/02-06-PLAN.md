  <name>Task 1: Create clean implementation</name>
  <files>internal/build/clean.go</files>
  <action>
Create internal/build/clean.go with clean functionality:

1. Define CleanOptions struct:
   ```go
   type CleanOptions struct {
       BuildDir string  // Build root directory (default: "build")
       Variant  string  // Variant to clean (e.g., "debug", "release")
       All      bool    // If true, remove entire BuildDir
   }
   ```

2. Define CleanResult struct:
   ```go
   type CleanResult struct {
       Path    string  // Path that was cleaned
       Existed bool    // Whether it existed before cleaning
   }
   ```

3. Implement Clean function:
   ```go
   func Clean(opts CleanOptions) (*CleanResult, error)
   ```

   Logic:
   a. Determine target path:
      - If opts.All: use opts.BuildDir
      - Else: use filepath.Join(opts.BuildDir, opts.Variant)
   b. Check if path exists (os.Stat)
   c. If exists, remove with os.RemoveAll
   d. Return CleanResult with path and whether it existed

4. Add output formatting:
   ```go
   func (r *CleanResult) String() string
   ```
   Returns:
   - If existed: "Cleaned: {path}"
   - If not existed: "Already clean: {path} (not found)"
  </action>

Run: `go build ./internal/build/...` compiles without errors
  </verify>
