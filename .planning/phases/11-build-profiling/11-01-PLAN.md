<task type="auto">
  <name>Task 1: Create Profiler type with timing collection</name>
  <files>internal/build/profiler.go</files>
  <action>
Create internal/build/profiler.go with:

1. CompileEvent struct:
   - Source string (source file path)
   - StartTime time.Time (relative to build start)
   - Duration time.Duration
   - ThreadID int (worker goroutine ID for Chrome Trace)

2. Profiler struct:
   - mu sync.Mutex (thread-safe access)
   - enabled bool
   - buildStart time.Time
   - events []CompileEvent

3. NewProfiler(enabled bool) *Profiler:
   - Initialize with current time as buildStart
   - Return pointer to new Profiler

4. Profiler.Start() method:
   - Record buildStart time
   - Called at beginning of build

5. Profiler.RecordCompilation(source string, start time.Time, duration time.Duration, threadID int):
   - If not enabled, return immediately (fast path)
   - Lock mutex
   - Append CompileEvent to events slice
   - Unlock mutex

6. Profiler.GetEvents() []CompileEvent:
   - Lock mutex, copy slice, unlock, return copy

7. Profiler.GetSlowestFiles(n int) []CompileEvent:
   - Get copy of events
   - Sort by Duration descending using sort.Slice
   - Return first n (or len if n > len)

8. Profiler.TotalBuildTime() time.Duration:
   - Return time.Since(buildStart)

9. formatDuration(d time.Duration) string helper:
   - If d >= time.Second: return fmt.Sprintf("[%.1fs]", d.Seconds())
   - Else: return fmt.Sprintf("[%dms]", d.Milliseconds())

10. Profiler.PrintSlowestFiles(n int, w io.Writer):
    - Get slowest files
    - Calculate total wall time
    - Print header: "\nSlowest %d compilation units:\n"
    - For each: print "  {duration}  {basename}  ({percentage}%)\n"
    - Use formatDuration for duration display
  </action>

<task type="auto">
  <name>Task 2: Create Chrome Trace JSON export</name>
  <files>internal/build/chrome_trace.go</files>
  <action>
Create internal/build/chrome_trace.go with:

1. ChromeEvent struct (JSON serializable):
   - Name string `json:"name"` (file basename)
   - Category string `json:"cat,omitempty"` ("compile")
   - Phase string `json:"ph"` ("X" for complete events)
   - Timestamp int64 `json:"ts"` (microseconds from build start)
   - Duration int64 `json:"dur"` (microseconds)
   - ProcessID int `json:"pid"` (always 1)
   - ThreadID int `json:"tid"` (worker ID)
   - Args map[string]interface{} `json:"args,omitempty"` (full file path)

2. ChromeTrace struct:
   - TraceEvents []ChromeEvent `json:"traceEvents"`

3. Profiler.buildChromeTrace() ChromeTrace method:
   - Create empty ChromeTrace
   - For each event in p.events:
     - Create ChromeEvent with:
       - Name: filepath.Base(event.Source)
       - Category: "compile"
       - Phase: "X"
       - Timestamp: event.StartTime.Sub(p.buildStart).Microseconds()
       - Duration: event.Duration.Microseconds()
       - ProcessID: 1
       - ThreadID: event.ThreadID
       - Args: map[string]interface{}{"file": event.Source}
   - Return trace

4. Profiler.WriteTrace(path string) error method:
   - Create file with os.Create
   - Defer close
   - Build chrome trace
   - Create json.NewEncoder(f)
   - Set encoder.SetIndent("", "  ") for readability
   - Encode trace
   - Return any error wrapped with context

Note: Use microseconds for ts and dur fields (Chrome Trace requirement).
Always include "args" with at least one field for event selection in UI.
  </action>
