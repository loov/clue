   - Verify source paths match

   - Create disabled profiler (enabled=false)
   - Record 3 compilations

   - Verify 0 events returned (fast path works)

4. TestProfiler_GetSlowestFiles:
   - Create enabled profiler
   - Record compilations with durations: 100ms, 500ms, 200ms, 1s, 50ms
   - Call GetSlowestFiles(3)
   - Verify returns 3 events
   - Verify order: 1s, 500ms, 200ms (descending)

5. TestProfiler_GetSlowestFiles_LessThanN:
   - Record 2 events
   - Call GetSlowestFiles(10)
   - Verify returns 2 events (not panic on n > len)

6. TestFormatDuration:
   - Test cases:
     - 2300ms -> "[2.3s]"
     - 1000ms -> "[1.0s]"
     - 999ms -> "[999ms]"
     - 450ms -> "[450ms]"
     - 50ms -> "[50ms]"
     - 1ms -> "[1ms]"

7. TestProfiler_PrintSlowestFiles:
   - Create profiler and record events
   - Create bytes.Buffer as writer
   - Call PrintSlowestFiles(3, buffer)
   - Verify output contains expected header
   - Verify output contains file names
   - Verify output contains percentages

8. TestProfiler_TotalBuildTime:
   - Create profiler and call Start()
   - Sleep briefly (10ms)
   - Call TotalBuildTime()
   - Verify duration >= 10ms

Create internal/build/chrome_trace_test.go with:

1. TestWriteTrace_ValidJSON:
   - Create enabled profiler
   - Record 3 compilations with known values
   - Create temp file
   - Call WriteTrace(tempFile.Name())
   - Read file contents
   - Unmarshal into ChromeTrace struct
   - Verify 3 events in TraceEvents
   - Verify no error on unmarshal (valid JSON)

2. TestWriteTrace_EventFields:
   - Create profiler with single known event
   - Write trace to temp file
   - Parse JSON
   - Verify event fields:
     - Name is basename of source file
     - Category is "compile"
     - Phase is "X"
     - ProcessID is 1
     - ThreadID matches input
     - Args contains "file" key with full path

3. TestWriteTrace_TimestampMicroseconds:
   - Create profiler with event: start=100ms, duration=50ms
   - Write trace
   - Parse JSON
   - Verify ts field is in microseconds (100000 for 100ms)
   - Verify dur field is in microseconds (50000 for 50ms)

4. TestWriteTrace_EmptyProfile:
   - Create enabled profiler but record nothing
   - Write trace
   - Verify file exists
   - Verify JSON has empty traceEvents array: {"traceEvents":[]}

5. TestWriteTrace_FileError:
   - Call WriteTrace with invalid path ("/nonexistent/dir/profile.json")
   - Verify error returned
   - Verify error message contains context

6. TestChromeTrace_PrettyPrint:
   - Write trace
   - Read file contents
   - Verify contains newlines and indentation (not minified)
  </action>
