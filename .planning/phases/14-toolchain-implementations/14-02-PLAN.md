  <name>Task 1: Create GCC toolchain package</name>
  <files>internal/toolchain/gcc/gcc.go, internal/toolchain/gcc/gcc_test.go</files>
  <action>
Create gcc.go implementing the GCC toolchain:

1. Package declaration: `package gcc`

2. Imports:
   - `fmt`, `os` for output
   - `github.com/loov/clue/internal/toolchain`
   - `github.com/loov/clue/internal/toolchain/gccish`

3. Toolchain struct with embedding:
   ```go
   type Toolchain struct {
       *gccish.Toolchain
   }
   ```

4. New constructor:
   ```go
   func New(cc, cxx, ar string, target toolchain.Platform) *Toolchain {
       return &Toolchain{
           Toolchain: gccish.New("gcc", cc, cxx, ar, target),
       }
   }
   ```

5. Override CompilerFlags to add GCC-specific behavior:
   - Call gccish CompilerFlags for base flags
   - Add sanitizer flags using gccish.SanitizerFlags(config.Sanitizers, true) - skipMemory=true for GCC
   - Add GCC coverage flags: -fprofile-arcs, -ftest-coverage if config.Coverage

6. Override LinkerFlags to add GCC-specific behavior:
   - Call gccish LinkerFlags for base flags
   - Add sanitizer flags (same as compiler, excluding memory)
   - GCC doesn't need explicit coverage linker flags (gcov links automatically)

7. Compile-time interface check:
   ```go
   var _ toolchain.Toolchain = (*Toolchain)(nil)
   ```

Create gcc_test.go with GCC-specific tests:

1. TestGCCToolchain_Name: verify Name() returns "gcc"

2. TestGCCToolchain_Sanitizers:
   - Test memory sanitizer is skipped with warning
   - Test address, thread, undefined sanitizers are included

3. TestGCCToolchain_Coverage:
   - Verify -fprofile-arcs and -ftest-coverage are added when Coverage=true

Remove gcc/.gitkeep since we're adding real code.
