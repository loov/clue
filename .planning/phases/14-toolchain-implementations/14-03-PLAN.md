<task type="auto">
  <name>Task 2: Create MSVC toolchain implementation</name>
  <files>internal/toolchain/msvc/msvc.go</files>
  <action>
Create msvc.go with MSVCToolchain implementation:

1. Package declaration: `package msvc`

2. Imports:
   - `fmt`, `os/exec`, `path/filepath`, `regexp`, `strings`
   - `github.com/loov/clue/internal/toolchain`

3. MSVC-specific flag mapping tables:
   ```go
   var optimizationFlags = map[string]string{
       "none":       "/Od",
       "size":       "/O1",
       "fast":       "/O2",
       "aggressive": "/O2", // MSVC has no /O3
   }

   var warningFlags = map[string][]string{
       "off":      {"/W0"},
       "default":  {"/W3"},
       "strict":   {"/W4"},
       "pedantic": {"/W4", "/permissive-"},
   }

   var debugFlags = map[string]string{
       "none":    "",
       "minimal": "/Z7",
       "full":    "/Zi",
   }
   ```

4. Toolchain struct:
   ```go
   type Toolchain struct {
       installation *Installation
       target       toolchain.Platform
   }
   ```

5. New constructor:
   ```go
   func New(installation *Installation, target toolchain.Platform) (*Toolchain, error) {
       if installation == nil {
           return nil, fmt.Errorf("nil MSVC installation")
       }
       return &Toolchain{installation: installation, target: target}, nil
   }
   ```

6. FindAndNew convenience function:
   ```go
   func FindAndNew(target toolchain.Platform) (*Toolchain, error) {
       installation, err := FindMSVC()
       if err != nil {
           return nil, err
       }
       return New(installation, target)
   }
   ```

7. Implement all 9 Toolchain interface methods (copy logic from internal/build/toolchain_msvc.go):
   - CC() returns "cl.exe"
   - CXX() returns "cl.exe" (MSVC uses same binary)
   - AR() returns "lib.exe"
   - Name() returns "msvc"
   - IsCrossCompiler() returns false (cross-compilation deferred)
   - String() returns "msvc (native)"
   - Identity() - use toolchain.GetCompilerIdentity with full path lookup
   - CompilerFlags(config) - MSVC-specific flags with /nologo, optimization, warnings, debug, CRT, /EHsc, /showIncludes
   - LinkerFlags(config, sysLibs) - MSVC-specific with /nologo, /DEBUG, foo.lib format for sysLibs

8. Helper functions:
   - `findTool(name string) string` - returns tool name (PATH resolution via Environment)
   - `findToolFullPath(name string) string` - finds full path in Environment["PATH"]
   - `fileExists(path string) bool`
   - `envMapToSlice(env map[string]string) []string`
   - `GetVersion(installation *Installation) (string, error)` - extract version from cl.exe

9. Compile-time interface check:
   ```go
   var _ toolchain.Toolchain = (*Toolchain)(nil)
   ```
