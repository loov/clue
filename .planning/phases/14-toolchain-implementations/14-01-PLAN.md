Create internal/toolchain/gccish package with shared GCC/Clang behavior.

Purpose: GCC and Clang share ~80% of their code (flag generation, path handling, cross-compilation). Extracting this to a shared package eliminates duplication and ensures consistent behavior between the two toolchains.

Output: gccish package with embeddable Toolchain struct that provides base implementation for CC(), CXX(), AR(), Name(), IsCrossCompiler(), String(), CompilerFlags(), LinkerFlags(), and Identity() methods.
</objective>

<task type="auto">
  <name>Task 1: Create gccish package with shared toolchain implementation</name>
  <files>internal/toolchain/gccish/gccish.go</files>
  <action>
Create gccish.go with a Toolchain struct that provides shared GCC/Clang behavior:

1. Package declaration: `package gccish`

2. Import required packages:
   - `fmt` for string formatting
   - `os` for stderr warnings
   - `github.com/loov/clue/internal/toolchain` for types and helpers

3. Create Toolchain struct with unexported fields:
   - cc, cxx, ar (string) - compiler paths
   - target (toolchain.Platform) - target platform
   - name (string) - "gcc" or "clang"

4. Create New constructor function:
   ```go
   func New(name, cc, cxx, ar string, target toolchain.Platform) *Toolchain
   ```

5. Implement all 9 Toolchain interface methods:
   - CC(), CXX(), AR() - return stored paths
   - Name() - return stored name
   - IsCrossCompiler() - check if cc contains "-linux-" or "-darwin-"
   - String() - return "name (cross)" or "name (native)" based on IsCrossCompiler()
   - Identity() - use toolchain.GetCompilerIdentity(cc)

6. CompilerFlags(config toolchain.Config) []string:
   - Add optimization flag via toolchain.OptimizationFlag(config.Optimize)
   - Add warning flags via toolchain.WarningFlagsForLevel(config.Warnings)
   - Add -Werror if config.WarningsAsErrors
   - Add debug flag via toolchain.DebugFlag(config.Debug)
   - Add -flto if config.LTO
   - Add -fPIC if config.PIC
   - Append config.RawCompiler flags
   - NOTE: Do NOT add sanitizers or coverage here - those differ between GCC/Clang

7. LinkerFlags(config toolchain.Config, sysLibs []string) []string:
   - Add -l{lib} for each sysLib
   - Add debug flag via toolchain.DebugFlag(config.Debug)
   - Add -flto if config.LTO
   - Append config.RawLinker flags
   - NOTE: Do NOT add sanitizers here - those differ between GCC/Clang

8. Add helper for sanitizer flag generation (called by GCC/Clang):
   ```go
   func SanitizerFlags(sanitizers []string, skipMemory bool) []string
   ```
   - If skipMemory is true, skip "memory" sanitizer with warning to stderr
   - Return slice of "-fsanitize=X" flags

Remove the gcc/.gitkeep file as we're replacing it with real code.
