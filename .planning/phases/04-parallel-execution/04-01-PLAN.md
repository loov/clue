2. ParallelResult struct to hold buffered output:
   - Source string

   - DepFile string
   - Output bytes.Buffer (buffered stdout/stderr)
   - Error error
   - Duration time.Duration

3. CompileParallel(ctx context.Context, sources []CompileOptions) ([]ParallelResult, error):
   - Use errgroup.WithContext(ctx) for automatic cancellation
   - Use g.SetLimit(jobs) for bounded concurrency (from golang.org/x/sync/errgroup)
   - For each source, g.Go() spawns a goroutine that:
     a. Captures output to bytes.Buffer instead of streaming
     b. Calls compiler.CompileSource with captured output
     c. Sends result to results channel
   - If !keepGoing: first error cancels context (errgroup default behavior)
   - If keepGoing: collect errors, continue processing all files
   - After g.Wait(), print buffered outputs atomically (complete chunks)

4. Progress tracking with sync/atomic:
   - completed atomic.Int64
   - total int
   - active []string (protected by mutex for active file list)

5. Output buffering strategy:
   - Create bufferedExecutor that wraps executor but captures to buffer
   - Use bytes.Buffer for stdout/stderr per compilation
   - After compilation completes, print entire buffer atomically

Key patterns from research:
```go
g, ctx := errgroup.WithContext(parentCtx)
g.SetLimit(jobs)

results := make(chan ParallelResult, len(sources))

for _, opts := range sources {
    opts := opts // Capture for closure
    g.Go(func() error {
        result := p.compileWithBuffering(ctx, opts)
        results <- result
        if result.Error != nil && !p.keepGoing {
            return result.Error
        }
        return nil
    })
}

err := g.Wait()
close(results)
```

```go
func (p *ParallelCompiler) compileWithBuffering(ctx context.Context, opts CompileOptions) ParallelResult {
    var buf bytes.Buffer
    start := time.Now()

    // Create a capturing executor (doesn't stream to stdout)
    captureExecutor := NewExecutor(ExecutorConfig{
        Verbose:      false,
        StreamOutput: false, // Capture, don't stream
        WorkDir:      "",
    })

    // Create temporary compiler with capturing executor
    tempCompiler := NewCompiler(captureExecutor, p.compiler.toolchain)

    // Run compilation
    result, err := tempCompiler.CompileSource(ctx, opts)

    // Build progress message for buffer
    fmt.Fprintf(&buf, "[%d/%d] Compiling: %s\n",
        p.completed.Add(1), p.total, filepath.Base(opts.Source))

    // Capture any compiler output
    // (executor captures to result, but errors go to stderr)

    return ParallelResult{
        Source:   opts.Source,
        Object:   opts.Output,
        DepFile:  result.DepFile,
        Output:   buf,
        Error:    err,
        Duration: time.Since(start),
    }
}
```

2. printResults method to atomically print buffered outputs:
```go
func (p *ParallelCompiler) printResults(results []ParallelResult) {
    for _, r := range results {
        if r.Output.Len() > 0 {
            fmt.Print(r.Output.String())
        }
    }
}
```
